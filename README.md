# CRICKSTATS-Salesforce-App
## Overview
CRICKSTATS is a Salesforce Lightning Application built to track player statistics, team performances, and match metrics seamlessly using custom architecture and automation.

## Features & Configuration
- **Custom Objects:** `Player__c` and `Match_Performance__c` with Master-Detail relationships.
- **Roll-Up Summary Fields:** Automatically calculates Total Runs, Total Wickets, Matches Played, and Average Score.
- **Screen Flow:** Embedded dynamic Flow on the Home page filtering players by Team using dynamic Data Tables.
- **User Interface:** Custom Lightning App and Home Page navigation bar tab organization.
